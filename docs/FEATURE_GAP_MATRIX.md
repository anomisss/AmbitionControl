# Ambition Control — Feature Gap Matrix (build 3233)

Compares Ambition Control against the **publicly advertised** feature list of Aluna's Trainer (Nexus Mods, Big Ambitions mod 2). The reference list is not evidence that a feature works on build 3233; evidence below comes only from Big Ambitions **build 3233** interop assemblies generated by MelonLoader 0.7.3 (`MelonLoader/Il2CppAssemblies`), inspected with a metadata dumper. No third-party code is used.

**Status values:** Verified (runtime evidence) · Partial-verified · Partial · Missing · Unsupported (no build-3233 API) · Investigate (candidate API found, behaviour/safety unknown).
**Risk:** L = runtime-only or reversible game option · M = persistent save change, reversible · H = persistent/progression, hard to reverse.
**API kinds:** `Cmd` = the game's own debug-console command (supported operation); `GV` = `GameInstance.gameVariables` custom-game option (persists in save); `Direct` = setting a field/property.

Last updated: 2026-11-19 (v0.7.0 development).

## Milestone order (adjusted to API evidence)

1. **B — Player utilities (now):** refill energy/hunger/happiness/all, invincibility, experimental hunger hold. All runtime-only, low risk, direct game setters.
2. **C/D — Game-variable controls:** tax %, market price multiplier, salary multiplier, rival difficulty, tutorial, unlock courses/contacts/importers — same proven GV mechanism, numeric bounds.
3. **C — Vehicles & time:** repair/refuel (game helpers), traffic, time speed; skip-hours only after confirming simulation is processed.
4. **D/E — Business & employees read-outs**, then guarded bulk edits with preview counts.
5. **F — Teleport, quests, rivals** (high-impact, confirmation required).
6. **G — Stabilization & v1.0 criteria.**
