# Ambition Control v0.3.0 — First native money controls

## Scope
- Live money read from `SaveGameManager.Current.Money`.
- Add, Remove, Set using `GameManager.ChangeMoneySafe` with a localized trainer transaction key.
- Stage → preview → confirm, re-check game save and balance before mutation.
- One-step undo that requires the same loaded save and unchanged balance.
- Read-only Energy, Hunger, Happiness, Day, Hour and Minute panels.
- Unity SDK manifest version bumped to 0.3.0.

## Verification status
- GitHub source only. **Not compiled in Unity or executed in Big Ambitions.**
- API signatures cross-checked against source published by official SDK and independent Big Ambitions modders.
- Money changes modify live game state; test a duplicate save, verify balance AND financial history.
