# v0.1.0 — Source starter archive note

**Historical baseline**: AmbitionControl_v0.1_SourceStarter.zip, delivered in the ChatGPT conversation before this repository was created.

This was an uncompiled proof-of-concept featuring a keyboard-toggle IMGUI menu, stage/confirm money commands, defensive fallback game bridge, and local settings.

It was **not a working money cheat**; the game adapter was intentionally unbound. It also required manual SDK entry-point work. GitHub v0.2.0 introduces the SDK-backed version.

Version numbering uses SemVer (`MAJOR.MINOR.PATCH`). Each new iteration should add a CHANGELOG entry and receive a distinct Git commit. Do not rewrite historical version commits.
