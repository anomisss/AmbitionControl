# Ambition Control

An independent, source-first utility and cheat-menu mod project for **Big Ambitions**.

## Releases
- **v0.1.0 — Source starter (previously delivered locally).** IMGUI proof of concept, F10, money command validation, disabled game bridge, optional API diagnostics. The original ZIP is retained in the ChatGPT project conversation; it was not compiled or tested in-game.
- **v0.2.0 — SDK integration (in development).** Official SDK lifecycle class and manifest, correct Unity assembly definition, improved metadata diagnostics.

See [CHANGELOG](CHANGELOG.md) and [docs/BUILDING.md](docs/BUILDING.md) after v0.2 lands.

This project is not affiliated with Hovgaard Games. Do not commit the game's proprietary DLLs or player saves.
